# Changelog

## 2026.11.28.2

- Publish the integration under the MIT License.

## 2026.11.28.1

- Support Home Assistant 2021.11.5 and newer with one HACS package.
- Update the sensor and map on older Core versions. Service response data is available from Home Assistant 2023.7.

## 2026.11.28

- Remove obsolete map markers from Home Assistant's state machine.
- Report failed Overpass lookups as action errors.

## 2026.11.23.1

- Added icon and light/dark wordmark in Home Assistant's brand image sizes.
- Lowered the verified Home Assistant minimum to 2024.4.0.

## 2026.11.23

- Added OSM/Overpass searches by person, home, or explicit coordinates, with a response action.
- Added a nearest-machine distance sensor and transient map markers, with available OSM location hints, source links, navigation links, and images.
- Added expanding search radii, bounded six-hour cache, German translations, and the shared hass-workflows CI pipeline.
